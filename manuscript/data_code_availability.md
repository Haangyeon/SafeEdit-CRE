# Data and Code Availability

All raw data, processed candidate tables, analysis scripts, model checkpoints, and environment files are archived in the permanent Zenodo repository at DOI: [10.5281/zenodo.21458489](https://doi.org/10.5281/zenodo.21458489).

The code repository is available at GitHub: [https://github.com/Haangyeon/SafeEdit-CRE](https://github.com/Haangyeon/SafeEdit-CRE).

The 600-parent CRE activity data used for training and evaluation is derived from the public MPRA dataset of Gosai et al. (2024), available in Supplementary Table 2 of that publication and in the accompanying Zenodo archive (DOI: 10.5281/zenodo.10698014).

All software dependencies are specified in the `environment.yml` and `requirements.txt` files included with the release.
